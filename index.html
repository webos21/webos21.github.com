crt_

앱은 네이티브로.
플랫폼 차이는 런타임 안으로.

  • Skia 그래픽과 Vulkan · D3D12 · Metal
  • 미디어, 애플리케이션 UI, 선택적 Web 임베딩

crt-cli_

SDK 선택부터 실행까지.
터미널에서 이어지는 개발.

CRT 기반 C/C++ 개발 환경을 관리하는 네이티브 CLI입니다. SDK 설치와 프로젝트 생성, 빌드, 테스트, 실행을 하나의 명령 체계로 연결합니다.

  • 정확한 버전을 고정하는 SDK 설치·검증
  • crt.json 프로젝트와 LLVM 직접 빌드
  • build → test → run 개발 워크플로

03 VS CODE 확장 </>

crt-vscode

VS Code에서 CRT 프로젝트를 열고 개발하세요.

CRT C/C++ 개발을 지원하는 TypeScript 확장입니다. VS Code 명령과 작업에서 crt-cli를 호출합니다.

  • crt.json 작업 영역과 CRT 작업 제공
  • Build, Test, Run, Doctor 명령 정의
  • clangd 연동과 확장 배포는 후속 계획

03 / THE WORKFLOW

아이디어에서 첫 실행까지.

익숙한 터미널에서,
명시적이고 재현 가능한 흐름으로.

  1. 01

    개발 환경 준비

    호스트에 맞는 CLI와 Dev SDK, 외부 LLVM 도구를 준비합니다.

  2. 02

    프로젝트 생성과 빌드

    C/C++ 프로젝트를 만들고 SDK와 도구 경로를 지정해 첫 빌드를 실행합니다.

  3. 03

    테스트하고 실행

    고정된 SDK와 도구 설정으로 빌드·테스트·실행을 반복합니다.

hello / terminal

# Dev SDK 설치 후 · 실제 LLVM 절대 경로로 변경

crt-cli new hello --language cxx
crt-cli build --project hello \
  --cc /path/to/clang \
  --cxx /path/to/clang++ \
  --linker /path/to/ld.lld \
  --ar /path/to/llvm-ar
crt-cli test --project hello
crt-cli run --project hello
❯C / C++ · CRT Dev SDK · LLVM

사용 흐름 예시입니다. SDK 설치와 운영체제별 사전 준비는 시작 가이드를 확인하세요.
